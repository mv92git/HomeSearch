# HomeSearch

A mobile-first React + TypeScript app for evaluating rental homes during broker visits.

## Checklist

- First impression, building access and common areas
- Interior condition, water, electrical, kitchen and bathrooms
- Society upkeep, parking, security and child safety
- Sector commute, metro, cabs and daily essentials
- Owner authority, agreement, deposit, inventory and handover

## Run locally

```bash
npm install
npm run dev
```

Visits are saved in your browser on this device. Use the compare page to review properties side by side. GitHub Actions deploys the built site to Pages on pushes to `main`.
